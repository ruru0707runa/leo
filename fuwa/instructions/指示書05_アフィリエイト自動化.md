# 指示書05 アフィリエイト自動化

目的: 商品調査から紹介投稿の作成・記録までを、エージェントへの一貫指示で回す。教材のManus丸投げプロンプトを、エージェント非依存の実行仕様に変換したもの（ふわでもそのまま実行できる）。

## 基本フロー
1. ジャンルと条件を指定する
2. エージェントが商品を調査・選定する
3. 投稿文を生成する
4. 表形式で記録し、共有できる形で出す
5. 人が内容を確認してから投稿する

## 調査の型（楽天ROOM型の例）
- 対象: 指定ジャンルの商品。絞り込み条件は「評価」と「レビュー件数」の両方に下限を設ける。
- 並び替えはレビュー件数順または評価順。上位10〜15件程度を選ぶ。
- 収集項目: 商品名／価格／評価／レビュー件数／URL／特徴／高評価の理由。
- 情報が取れない項目は「未確認」と書く。推測で埋めない。

## 投稿文の型
- 長さ: 150〜250字程度（媒体に合わせて調整）。
- 視点: 実際に使った人の視点で書く。ただし使っていない商品を「使った」と偽らない。使っていない場合は、評価・レビューから読み取れる範囲の紹介に留め、その旨が伝わる書き方にする。
- 構成: 使用感や具体的な良さ → 向いている人 → 明るい締め。
- 禁止: 誇張した断定的な表現、効果の保証、宣伝くさい定型文の連発。
- 量産時は各投稿で表現を変え、同じ文章の繰り返しにしない。共感を呼ぶ言い回しを入れる。

## 紹介投稿（汎用型）
- 指定ジャンルについて、買い手目線の紹介投稿を複数パターン作る。
- 商品選定 → 投稿の型（体験談風、比較、ランキング等）→ リンクの置き方（本文ではなくプロフィールや続きへの誘導など媒体の作法に従う）→ 反応の記録。
- 短期の売上より、継続できる発信設計を優先する（発信が止まれば自動化も止まるため）。

## ブログアフィリエイト
- テーマ・構成・見出しの型を固定し、記事を一括生成 → 内部リンク・画像・メタ情報を整備 → 事実確認をして公開（指示書02のブログ量産と共通）。
- 紹介であることの表示など、法令・媒体規約に関わる部分は現行ルールを確認して入れる。

## プラットフォーム内アフィリエイト
- 販売プラットフォーム（深夜マーケット等）自体のアフィリエイトは、紹介リンクの作成 → 短縮して見た目を整える → 貼り付け後に表示を確認、が手順の型。
- 報酬率や条件は各プラットフォームの現行表示で確認する。

## 成果物
調査表（収集項目を列にした表＋共有リンク）＋投稿文セット（パターン別）＋投稿後の記録表（日付／商品／反応）。
