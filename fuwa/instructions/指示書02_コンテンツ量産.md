# 指示書02 コンテンツ量産

目的: SNS投稿・動画台本と素材・図解・音声などの定型コンテンツを、型と道具で量産できる状態にする。量産の前提は、発信の戦略（誰に・何を・なぜフォローするか）が決まっていること。戦略は別途シンスレッズ側の指示書で決め、ここでは実装だけを扱う。

## 量産の基本形
1. 型（テンプレート）を先に作る: 構成・口調・禁止事項を固定する。
2. 変数だけ差し替える: テーマ、ターゲット、一次情報（自分の経験・データ）。
3. 生成 → 人の承認 → 予約・配信 → 記録、の順で回す。承認なしの自動投稿はしない。
4. 反応の記録を型の改善に使う（どのスタイルが伸びたかを蓄積する）。

## 投稿文の量産
- プロンプトテンプレのライブラリを使う（教材内「スキル100個」の分類が参考になる: SNS投稿／note記事／LINE／商品設計／集客／心理学・コピー／業務効率化／教育）。必要なカテゴリだけを自分の型に直して使う。全件消化は目的ではない。
- 投稿生成ツールの設計（ThreadsBuzz型）: 入力はジャンル・キーワード・ターゲット・伝えたいメッセージ。切り口（スタイル）とトーンを分けて選べるようにする。スタイルの例: 常識破壊、ロードマップ、プロフィール誘導、需要確認、ストーリー、権威性、共感、数字インパクト、問いかけ、リスト。生成は1回に少数（質を保てる範囲）で、エクスポートして記録に残す。
- 投稿文の質の担保: 一次情報のない量産は薄くなる。生成前に「自分の経験・検証・数字」を素材として必ず渡す。

## ショート動画（リール）の量産
- プロンプトテンプレ方式: 変数（ジャンル／テーマ／商品・サービス名／シーン内容）を差し替えて動画生成AIに渡す。
- 共通ルール（教材の型）: 全て動画素材で構成する。1〜2秒ごとにシーンや背景を切り替える。字幕を付ける場合は1シーン1行・大きめサイズ。尺は15〜30秒を目安に指定する。
- 構成パターンを使い分ける: シンプル解説／ランキング／ビフォーアフター／ステップ解説／問いかけ・共感／アバター解説／アバター＋実写ミックス。
- 品質のコツ: 映像の色調の方向性、字幕の書体と影、トランジションの種類をプロンプトで明示すると安定する。

## 図解の量産
- GeminiのGem等で図解作成を定型化する（縦長図解、ステップ図、比較図などのパターンを用意）。
- 運用の型: 文章（投稿や台本）を先に作り、それを貼り付けて画像生成に切り替える。サイズと、アイコン等の定位置要素を指定する。
- キーワード入力でサムネイルを量産する使い方も可能だが、図解の中身の正確性は人が確認する。

## 音声の自動化
- 音声クローン（Fish Audio型）: 短い音声サンプルから自分の声のモデルを作り、台本を読み上げさせて動画ナレーションや音声コンテンツに使う。
- 注意: 声のモデルを公開設定にすると他者の検索に出る。公開範囲を必ず確認する。他人の声の無断使用はしない。
- 料金プランで生成できる長さと品質が変わるため、用途（短尺ナレーション中心か、長尺か）で選ぶ。

## ブログ記事の量産
- 型: テーマ・構成・見出しのパターンを先に固定し、生成AIで一括生成 → 内部リンク・画像・メタ情報を整える → 品質チェックして公開。
- 品質チェック項目: 事実の誤り、重複した内容、一次情報の有無、見出しと本文の一致。

## 記録と改善
- 生成物は必ず記録に残す（投稿管理のシートやNotion等）。記録項目: 日付／テーマ／使った型／反応（表示・いいね・フォロー増）／学び。
- 週1回、反応の良かった型を残し、悪かった型を直すか捨てる。

## 成果物
量産セットアップ表（コンテンツ種別ごとに: 使う型／使う道具／変数の一覧／承認者／記録先）＋テンプレート一覧。
